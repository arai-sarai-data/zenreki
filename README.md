# 土地の前歴

住所を入れると、その土地が昔なんだったか（海・川・田んぼ・湿地・台地…）を「前歴書」にして出す静的サイト。

- 前歴書：明治期の低湿地データ、地形分類（自然地形・人工地形）、標高、洪水・高潮・津波の浸水想定、土砂災害警戒区域
- 証明写真：その地点の1945〜50年（なければ1961〜69年、1974〜78年）の空中写真を切り出し
- 今昔くらべ：昔と今の地図・空中写真を左右スワイプで比較
- 散歩ログ：GPX / GeoJSON / KML を明治の地図に重ね、歩いた道の何%が水・田・湿地だったか数える（ファイルは送信しない）
- この辺りの写真：Wikimedia Commons の位置情報つき写真を古い順に

## しくみ

サーバーもデータベースも持たない。閲覧者のブラウザが、国土地理院・ハザードマップポータル・Wikimedia Commons の公開タイル／APIから直接読み、
タイル画像の色や地形分類のベクトルタイルをその場で判定する。

## 出典

国土地理院（地理院タイル、ベクトルタイル「地形分類」、明治期の低湿地データ、治水地形分類図、標高タイル、住所検索・逆ジオコーダ）、
国土交通省 ハザードマップポータルサイト、Wikimedia Commons。地形分類の解説文は地理院地図のものをそのまま使っている。
